OJ. CREST GROUP LTD — Store + Admin

THIS ZIP MUST BE EXTRACTED BEFORE UPLOADING.

Files that must sit together in the ROOT of your GitHub Pages published folder:
index.html
admin.html
styles.css
app.js
assets/oj-crest-logo.png

GitHub Pages instructions:
1. Open your GitHub repository.
2. Upload the CONTENTS of this extracted folder (not just the ZIP file).
3. Keep styles.css, app.js, index.html and admin.html in the same root folder.
4. Keep the logo at assets/oj-crest-logo.png (the assets folder matters).
5. In Settings > Pages, publish the branch/folder where index.html exists.
6. Wait for the deployment to finish, then reload the website. If needed, clear browser cache.

If index.html is placed in a subfolder but styles.css and app.js are not beside it, the page will look unstyled and the logo will be broken.

Important: This is a front-end prototype. LocalStorage data is only stored in the current browser and does not sync across customers/devices. Real online selling requires a shared hosted database, secure admin login/server permissions, and verified payment integration. The checkout is a demo and does not collect money.
